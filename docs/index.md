## Documentação para desenvolvedores

Esta documentação explica como registrar uma aplicação e integrá-la ao Central Macatuba - ID. Os exemplos e orientações públicas são limitados às funcionalidades disponibilizadas pelo serviço.

::: warning Estado de disponibilidade
A presença de uma funcionalidade nesta documentação não significa, por si só, que o serviço esteja liberado para produção. Antes de integrar, consulte os metadados de descoberta e o [estado do serviço](/status).
:::

## Sobre o projeto

O Central Macatuba - ID é um serviço independente e gratuito do projeto Central Macatuba. Não possui vínculo com a Prefeitura Municipal de Macatuba.
